Set up 2 Nov 2026 · how sessions stay in sync

Working in the cloud

From 2 Nov 2026 the owner always works in cloud sessions, at home as well as overseas. The site, the API and every automatic job already run on Railway and Vercel, so they don't move. What moves is the Claude workflow: publishing news, running scripts and changing code, which until now ran on the laptop. It moves to a Claude Code cloud session in the Code tab of the Claude app.

The database connection: solved with the bridge. Cloud sessions can't connect to Neon directly: outbound traffic goes through an HTTP/HTTPS proxy and direct database connections are blocked. Scripts instead use the database bridge, which sends each call through the Railway API (DB_BRIDGE_URL). It passed its read and write tests from a cloud session on 2 Nov 2026.
How every session stays in step (from 25 Nov 2026). GitHub main is the shared copy. Cloud sessions start from a fresh copy of it, and the laptop session pulls it automatically when it starts or resumes. This log's source is docs/session-log/index.html in the repo: each session adds its entry in the same commit as the work, then republishes this page to the same link. News published by script isn't in git, so it gets a short entry here too.
  • 1. Owner: connect GitHub. At claude.ai/code, give Claude access to abzydey/footy-feed-website.
  • 2. Owner: create the cloud environment. The environment holds DB_BRIDGE_URL and ADMIN_JWT_SECRET only. Enter them only on that settings screen, never in chat.
  • 3. Claude: prepare the repo. Copy laptop-only memory rules into CLAUDE.md, and commit a start-up hook that installs dependencies and generates Prisma in cloud sessions.
  • 4. Test. Passed from a cloud session on 2 Nov 2026: database read and write through the bridge, a push to main and a session log update. Still to do from the phone: publish a real story with a screenshot, and confirm the notification.
  • 5. Owner: run a Codemagic build so the apps have the free agency page and all October changes.
  • 6. Owner: check account access from the phone. Railway, Vercel, Neon, GitHub, Codemagic, Firebase and X, with a password manager and backup codes. Check that any code sent by SMS will arrive overseas, and that billing and X API credit won't lapse.
  • 7. Owner: set up the backup. Log in to /admin on the phone and turn on admin alerts. It can post a story if Claude can't, but it doesn't cover the tracker scripts or pinning the team-list link.
